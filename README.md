# ⚡ Sigma Web Dev - Android & Web Learning App (Gen-Z Edition)

Learn Full-Stack Web Development based on **CodeWithHarry's Sigma Web Development Course** with an integrated AI Chatbot tutor, trilingual language support (Hindi, English, Hinglish), persistent user authentication & progress tracking, and an interactive code playground.

---

## 🚀 Key Features

1. **Course Curriculum & Video Lessons**:
   - Structured modules from **Tutorial #1: Installing VS Code & How Websites Work** (`tVzUXW6siu0`) to full-stack projects.
   - Embedded YouTube player for distraction-free learning.
   - Interactive quizzes with XP rewards and instant feedback.
2. **Gen-Z Aesthetics & Gamification**:
   - Cyberpunk dark-mode palette (`#090d16`), electric violet, neon cyan, and glowing accents.
   - Streak counter (🔥), XP system (⚡), levels, and achievement badges (*Sigma Rookie*, *CSS Alchemist*, *JS Sorcerer*, *Sigma Fullstack God*).
   - Confetti fireworks on completing lessons and passing quizzes!
3. **Trilingual Toggle (Instant Switch)**:
   - 🇮🇳 **Hinglish**: Fun, conversational Gen-Z style ("Arre bro, flexbox centering trick no cap!").
   - 🇮🇳 **हिंदी (Hindi)**: Clean, fluent Hindi explanations.
   - 🌐 **English**: Professional dev vocabulary.
4. **SigmaBot - AI Coding Buddy**:
   - 24/7 coding tutor with knowledge of HTML, CSS, JavaScript, Node, Express, MongoDB, and DOM bugs.
   - Formatted code snippets with one-click copy.
5. **In-App Code Lab (Playground)**:
   - Live HTML, CSS, and JS editor with instant browser preview in an isolated sandbox.
6. **Authentication & Persistence**:
   - Full Sign-Up and Sign-In flow with bcrypt password encryption, JWT tokens, and SQLite/JSON database.
7. **Android Mobile Optimized**:
   - Mobile-first layout with bottom navigation dock and touch-friendly actions.
   - Android PWA manifest enabled: Open in Chrome on Android and tap **"Install App"** / **"Add to Home Screen"** to run as a native mobile app!
   - Built-in Desktop Simulator toggle (switch between fullscreen and Android Frame view).

## 🛠️ How to Run

### Step 1: Start both Backend and Frontend
In the project directory, run:
```bash
npm start
```
or:
```bash
node start.js
```

### Step 2: Open in Browser or Mobile
- **On PC / Laptop**: Open [http://localhost:3000](http://localhost:3000)
- **On Android Phone**: Make sure your phone is connected to the same Wi-Fi, then open `http://<YOUR_IP>:3000` (the IP will be displayed in your terminal when running `npm start`).
- Tap **"Add to Home Screen"** on Chrome for Android to use it full-screen like a native app.
